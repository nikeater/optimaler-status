Every icon is a `currentColor` stroke on a 24-unit grid, so it inherits the colour of the text beside it and scales with the reader's font size (the `.icon` class sizes it in `em`). No sprite sheet, no icon font, no remote file: the same rule as the typeface (ADR-030) and for the same reason. THREE RULES, and they are the accessibility floor rather than taste. 1. Every icon is `aria-hidden="true"` and `focusable="false"`.
